# The Cleaner - cleaning systems milestone

## Run

1. Extract this folder.
2. Open `project.godot` in Godot 4.7.2.
3. Press **F5**.

## Controls

- **WASD**: move
- **Mouse**: look around
- **E**: interact with dust, spider webs, and the sofa
- **Escape**: release or recapture the mouse

The room now has a 10-minute countdown, a ceiling, dim colored ceiling lights, six scattered translucent dust piles, four corner spider webs, and the sofa pickup/place task.

Dust and web tasks take 10 seconds each. Look at a task and press **E** once to start cleaning; the interaction prompt shows live progress until it disappears.
